## Agent skills

When a skill says "Load the `X` skill" and this harness has no skill tool, find that skill's `SKILL.md` and read it.

### Issue tracker

Local markdown under .scratch/<feature>/. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary. See `docs/agents/triage-labels.md`.

### Context docs

Single-context. See `docs/agents/context-docs.md`.

### Checks

Before a commit, and before writing any verification helper, run the repo's checks. See `docs/checks.md`.

### Model tiers

Tickets record a Model tier, never a model name. See `docs/agents/model-tiers.md`.
