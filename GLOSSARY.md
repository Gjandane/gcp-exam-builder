# GCP Exam Builder

A study workflow for Google Cloud certification exams: an AI skill builds a question bank, and a Google Sheets app runs practice and simulated exams from it.

## Question bank

**Question bank**:
The full set of questions for one exam, each with its choices, correct answers and explanation.
_Avoid_: Question pool, dataset, dump

**Lineage**:
Where a question came from: `scraped` (pulled from a source), `given` (supplied by the user, written or typed in from elsewhere), or `created` (generated by the LLM).
_Avoid_: Origin, source type

**Curated site**:
A known question site that gets its own reusable scraper script.
_Avoid_: Target site, source site

**Uncertain answer**:
An answer the source itself marks as unclear or disputed, one where two sources disagree, or one from a source not trusted for answers that no trusted source matches. An LLM answer given with `low` confidence to a question that had none is also one, and so is a user answer the LLM disputes, or an LLM answer that a user-written explanation contradicts. A re-check confirm with `high` confidence clears it, even while sources still disagree.
_Avoid_: Unverified answer, weak answer

**Batch**:
The unit of work one LLM session takes on: a small set of questions (default 5, 20 for Subdomain tagging), or one source page in an LLM scrape.
_Avoid_: Chunk, page

**Section**:
A top-level part of the official exam guide (e.g. Section 2) that groups Subdomains and carries a published share of the exam.
_Avoid_: Domain, area

**Subdomain**:
A numbered part of a Section (e.g. 2.1) that each question is tagged with.
_Avoid_: Topic, category, domain (when the numbered sub-section is meant)

**Demo bank**:
A small Question bank of original questions written for the project, safe to show in public. It never holds scraped or given questions.
_Avoid_: Sample bank, test bank, fixture bank

**Study guide**:
An optional set of chapters, one per Subdomain, teaching the concepts its questions test.
_Avoid_: Notes, reviewer, cheat sheet

## Study app

**Review mode**:
Practice where each answer is graded at once and followed by its explanation.
_Avoid_: Practice mode, study mode

**Mock Test**:
A timed, randomized exam simulation, graded only at the end.
_Avoid_: Practice exam, quiz

**Bookmark**:
A mark the user puts on a question to find it again later in Review mode.
_Avoid_: Save, favourite, star

**Flag**:
A mark the user puts on a question during a Mock Test to revisit it before submitting.
_Avoid_: Mark for review (when Report is meant)

**Report**:
A user mark saying a question's answer or explanation looks wrong, queued for the skill to re-check.
_Avoid_: Flag, complaint
